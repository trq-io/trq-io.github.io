Same model, same project — one session is genius, the next is trash. You rate
it. The file stays on your machine. Later, `trq week` shows how the last seven
days actually felt.

---

## Five words

| | |
|---|---|
| **genius** | It landed. You'd run that session again. |
| **good** | Solid. A few nicks. |
| **fine** | It got there. Nothing to write home about. |
| **meh** | More steering than shipping. |
| **trash** | Time you won't get back. |
| **restart** | Optional flag. Same session, take two. |

## How it works

1. End a session in Claude Code or Codex.
2. Type `/track good` — or `genius`, `fine`, `meh`, `trash`.
3. Run `trq week` when you want the weather.

## What it is not

- **Not Artificial Analysis.** We don't rank models.
- **Not LangSmith.** We don't trace production calls.
- **Not a vibe board.** No public feed. No scores for show.

## Privacy

The CLI never phones home. One JSON line per session, appended to
`~/.trq/sessions.jsonl` on the machine that ran it.

No account. No telemetry. No analytics on this page.
